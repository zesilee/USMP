# Proposal — nce-batch-commit（NCE 配置台二期：攒批提交工作流）

## Why

一期（nce-console-redesign，已归档 2026-07-31）完成了配置台界面与交互对齐，但提交语义仍是「表单确定=立刻下发设备」：无法一次核对多处修改、无法预览将要发给设备的报文、误操作直达设备、字段清除表达不了设备侧删除。NCE 目标形态（`~/ui/` 截图：变更内容界面 / 试运行结果 / 网元数据差异对比）的核心是**攒批**：编辑先进「待提交变更集」，经 变更内容 diff 核对、试运行报文预览后一次提交，可随时重置反悔。一期已为此预留右上工具栏区域与多选列。

**范围拍板（2026-07-31 与用户确认）**：
1. **完全改攒批**——表单「确定」只入变更集，右上「提交配置」才真正下发；即时下发路径退役，不做双模式并存。
2. **失败整体回退**——一次提交内多条变更原子生效：任一失败则设备回到提交前状态，不留半成品配置。
3. **导出/配置项两个按钮本期不做**——聚焦「攒批→变更内容→试运行→提交/重置」闭环。

## What Changes

- **前端变更集**：新增 changeset Pinia store（设备维度，含 新增/修改/删除 三类条目，定位=设备+锚点路径+list 主键）；详情区/表单 Tab「确定」改为写入变更集（**BREAKING**：不再即时下发）；行删除改为入变更集的删除条目（**BREAKING**：不再即时 DELETE）；字段级清除升级为「变更集内该叶删除」语义（一期「本地不下发」文案退役）。
- **右上工具栏**（一期预留区域）：变更内容（带未提交数徽标）| 试运行 | 重置 | 提交配置 四按钮 + 「检索到新内容变更，请及时提交」提示条；无变更时后三者禁用。
- **变更内容弹窗**：树形三列（属性/变更前/变更后）+ 增加/修改/删除计数图例与着色（对齐截图）。
- **试运行弹窗**：Tab①待下发设备数据=按设备展示正向报文/回滚报文双栏 XML；Tab②网元数据差异对比=以设备实时回读为基线的树形 diff。只算不下发。
- **提交配置**：变更集整体下发，单设备内跨模块原子（candidate 两阶段：全部 edit-config 成功才 commit，任一失败 discard 整体回退）；提交成功清空变更集并刷新列表/新鲜度；失败如实报错、变更集保留。
- **重置**：确认后清空变更集，恢复各表单为设备实际态。
- **多选批量删除**：多选列接通「更多▾」批量菜单（批量删除→批量入变更集删除条目）。
- **后端新增契约**（一期零后端变更不再成立）：试运行预览接口（入参=变更集，出参=正向/回滚 XML + 结构化 diff 树）与批量提交接口（原子下发变更集，含删除条目）；复用既有 diff 引擎、xmlcodec 编码器、intent 2PC 协调器（需补删除类变更支持）。
- 附带小债：string length 约束元数据经 schema 透出，使一期「合法长度」占位自动生效。

不做（后续期）：导出、配置项、跨设备联合变更集（本期变更集按当前选中设备隔离）、confirmed-commit 网络级回滚演练。

## Capabilities

### New Capabilities

- `config-changeset`: 变更集服务端契约——试运行预览（正向/回滚报文生成、以实时回读为基线的差异计算，纯计算不下发）与批量原子提交（单设备跨模块 candidate 两阶段、删除条目支持、失败整体回退、成功后审计与对账触发）。

### Modified Capabilities

- `frontend`: FE-03 提交主链路改为攒批（表单确定→变更集，提交配置→批量下发）；FE-11 行删除与多选批量改为入变更集；FE-16 即时删除交互退役；FE-21 详情区提交编排改攒批；FE-22 字段级清除升级为变更集内 leaf 删除语义；新增 FE-23 攒批工具栏与三弹窗（变更内容/试运行/重置确认）。

## Impact

- 后端：`internal/api` 新增 preview/batch-commit handler 与路由；`pkg/yang-runtime/client.marshalChange` 编码分派逻辑提取为可导出纯函数；`internal/intent` TxCoordinator/Fragment 补删除语义（BIO-03 既有行为不变）；审计复用 OA-01 挂点（每设备+路径一条）。
- 前端：新增 changeset store + 工具栏组件 + 变更内容/试运行弹窗；改 `ItemDetailPane`/`ModuleListTab`/`ModuleFormTab`/`useConfigSubmit`/`configDiff`（补删除表达）；i18n 新增 `console.batch` 域双语。
- 测试：后端 B1（diff/编码/回滚反算 纯函数+race）+ B2（netconfsim candidate/discard 端到端：试运行不改设备、提交原子性、失败回退）+ B3（新端点契约）；前端 F1（changeset store/diff）+ F2（工具栏/弹窗/表单改攒批）+ F3（真浏览器弹窗交互）+ F4（staging-smoke 提交链路断言全部改写为攒批）；覆盖率棘轮不下降（T08）。
- 派生黄金：不涉及 deriveTabs/deriveColumns 等派生函数变更，GD-01 黄金不刷新。
- 风险：即时下发退役是全链路交互 BREAKING，F4 断言面大；2PC 与周期对账的 desired 写入时序需明确（design 展开）。
